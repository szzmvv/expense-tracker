# Expense Tracker

Учебное консольное приложение для учёта расходов на Python.

## Возможности
- Добавление названия и суммы расхода.
- Проверка ввода: обработка текста, нуля и отрицательных сумм.
- Просмотр расходов, их количества и общей суммы.
- Сохранение и загрузка данных в JSON.

## Запуск
Требуется Python 3. Дополнительные библиотеки не нужны.

python3 main.py

Для завершения ввода введите «выход».
Данные сохраняются в expenses.json в текущей папке.

## Ограничения
- Повреждённый JSON-файл пока не обрабатывается.
- Для сумм используется float; точное хранение денежных значений
  планируется добавить позже.
