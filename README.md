# Expense Tracker

Учебное консольное приложение для учёта расходов.
Стек: Python, SQLite, Git.

## Возможности
- Добавление расходов с названием, суммой и категорией.
- Просмотр списка, количества расходов и общей суммы.
- Удаление расхода по номеру.
- Подсчёт суммы по выбранной категории.
- Проверка пользовательского ввода.
- Автоматическое сохранение в SQLite.
- Однократный импорт старых данных из JSON.

## Запуск
Требуется Python 3. Дополнительные библиотеки не нужны.
Команды выполняются из папки проекта.

python3 main.py

## Меню
- 1 — добавить расход;
- 2 — показать расходы;
- 3 — удалить расход;
- 4 — показать сумму по категории;
- 0 — выйти.

## Хранение данных
Основное хранилище — expenses.db.
База и таблицы создаются автоматически при запуске.

Для переноса прежних данных из expenses.json:
python3 import_json.py

Повторный запуск импорта не добавляет записи заново.
Исходный JSON не изменяется.

## Ограничения
Суммы хранятся как REAL и обрабатываются через float:
возможны погрешности дробных вычислений.
