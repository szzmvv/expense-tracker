# Expense Tracker

Учебное консольное приложение для учёта расходов на Python.

## Возможности
- Добавление названия и суммы расхода.
- Проверка ввода: обработка текста, нуля и отрицательных сумм.
- Просмотр расходов, их количества и общей суммы.
- Удаление расхода по номеру с проверкой ввода и возможностью отмены.
- Категории расходов и подсчёт суммы по выбранной категории.
- Сохранение и загрузка данных в JSON.
- При повреждённом формате JSON программа сообщает об ошибке
  и завершается, не изменяя файл.

## Запуск
Требуется Python 3. Дополнительные библиотеки не нужны.

python3 main.py

## Использование
После запуска выберите действие:
- 1 — добавить расход;
- 2 — показать расходы и итог;
- 3 — удалить расход;
- 4 — показать сумму по категории;
- 0 — выйти.

Новый расход автоматически сохраняется в expenses.json.

## Ограничения
- Повреждённый JSON-файл пока не обрабатывается.
- Для сумм используется float; точное хранение денежных значений
  планируется добавить позже.
